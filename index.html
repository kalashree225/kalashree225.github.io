The three-line ritual

Good prompts feel
like good briefs.

Skills are not buttons to mash. Give them a clear destination, the boundary of the work, and the proof you want at the end.

  1. 01
    Name the outcome.

    “Build a responsive dashboard…”

  2. 02
    Set the edges.

    “…touch only these files; keep the API stable.”

  3. 03
    Ask for proof.

    “…run the targeted tests and show what changed.”
